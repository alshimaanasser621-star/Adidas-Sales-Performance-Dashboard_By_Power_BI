# Adidas Sales Performance Dashboard

## Project Overview
This Power BI dashboard analyzes Adidas sales performance across regions, retailers, products, and sales methods.

## Tools
- Power BI

## Dashboard KPIs
- Total Sales: $900M
- Profit: $332M
- Average Operating Margin: 42%
- Units Sold: 2M

## Analysis
The dashboard provides insights into:
- Sales by Region
- Sales by Retailer
- Sales by Product
- Sales by Sales Method
- Sales Trends by Year

## Key Insights
- West region generated the highest sales.
- In-store sales represented the largest sales method.
- Men's Street Footwear was the top-selling product category.
- West Gear had the highest retailer sales.
